# Neon Drive

A synthwave slot game built with PixiJS and TypeScript. **Play money only.**

Play it: https://neon-drive-green.vercel.app (add `?demo=bonus` or `?demo=bigwin` to make the first spin a real free-spins round or big win).

- 5 reels × 3 rows, 243 ways (adjacent reels from the left, wilds on reels 2–4)
- Free spins: 3 / 4 / 5 scatters award 8 / 12 / 20 spins; the multiplier climbs by 1 after every winning free spin; 3 scatters in the bonus add 5 spins
- Round wins capped at 5,000× the bet

## Math

| Metric | Target | Simulated (60M rounds) |
|---|---|---|
| RTP | 96% | 96.15% ± 0.23% |
| Base game / free spins | ~64% / ~32% | 64.8% / 31.4% |
| Hit frequency | ~25% | 24.5% |
| Bonus frequency | ~1 in 150 | 1 in 159 |
| Std dev per spin | medium-high | 9.2× bet |

The math engine (`src/math`) is pure TypeScript with no rendering code: config + bet + RNG in, complete round out. The game and the simulator use the same engine, so the numbers above describe the game you play.

- `src/math/neon-drive.json`: reel strips, paytable and bonus settings. Generated by `scripts/build-config.ts`.
- `npm run analyze`: rebuild the config and print exact base-game stats plus sampled bonus value. This is the tuning loop.
- `npm run sim -- --spins 60000000`: full-game verification across worker threads.
- `npm test`: unit tests for ways evaluation, scatters, multiplier, retriggers, the win cap, and agreement between exact and sampled numbers.
